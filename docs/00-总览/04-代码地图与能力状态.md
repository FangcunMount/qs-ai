# 代码地图与能力状态

## 结论

源码基线 `c977cb9` 已具有持久治理、评测、发布、解读执行与消息交付实现。本文只描述可回查的仓库能力；CI、已部署镜像、实际模型行为和用户验收需要独立日期证据。目录存在不证明所有未来产品能力已完成。

## 实际代码责任

| 层/模块 | 实现位置 | 主要依赖和边界 |
| --- | --- | --- |
| 组合根 | bootstrap | Settings、Dishka、资源创建、监督与关闭 |
| 入站映射 | transport/http、transport/grpc | 健康指标、可信工作负载、机器DTO、错误与用例 |
| 解读领域 | domain/interpretation | Session、EvidenceSet与状态不变量 |
| 资产与发布领域 | domain/governance | 定义、冻结、适用范围、发布规则 |
| 评测领域 | domain/evaluation | 候选、质量、审核、取消和复审规则 |
| 执行应用支持 | application/execution | 任务、冻结配置、模型调用、容量与恢复 |
| 具体适配 | infrastructure | MySQL、QS、防腐映射、模型、图和MQ |

[架构测试](../../tests/test_architecture.py) 检查依赖方向和导入循环：domain/application 不依赖具体框架及基础设施；bootstrap 拥有装配，transport 不直接读写 ORM。测试是边界保护，不是架构设计正文。
