## 准入拒绝处理原则

QS 已可靠接收的合法请求，若 AI 无法绑定发布快照，不创建执行任务，
而是在同一事务中保存 blocked 会话、原请求幂等回执和结果 Outbox。
这不是执行准入成功：无配置绑定、无执行 Job、无模型调用。
发布恢复后重放旧 ID 仍返回原拒绝，不能偷偷改绑新配置。
没有已接受配置的拒绝记录不允许走“重试原执行配置”入口。
数据库、通信或提交结果未知仍抛出可重放错误，不能误记为确定失败。

用户可重新提审小程序，必要的端侧修复不受当前审核版本限制。
