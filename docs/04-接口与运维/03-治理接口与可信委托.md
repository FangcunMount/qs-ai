# 治理接口与可信委托

现行说明；源码基线 `c977cb9`。QS 负责每次管理权限校验，AI 负责资产、评测和发布的领域规则。Operating 是管理客户端，不计算权限、预算或发布门槛。

## 工作负载与操作者

[gRPC 注册](../../src/qs_ai/bootstrap/grpc_server.py)仅在 `grpc.governance_enabled=true` 时注册治理服务；入站服务验证 mTLS 的 `qs-apiserver.svc` 工作负载。可信委托包含 QS 校验后的机构、操作者与资源范围，不能由浏览器自行声明。AI 不签发用户令牌，不复制 IAM 用户与关系目录。

读取审计、组织管理员写入、候选审核职责和发布确认是不同能力。QS 根据实际入口做权限校验；AI 在组织隔离、命令回执归属、版本 CAS 与审核分离规则上继续约束。具体用户权限由 QS/IAM 的当前实现决定，不能仅靠服务证书放行。

## 服务地图

服务和精确字段以 [workflow.proto](../../integrations/workflow/proto/workflow.proto) 为准；以下解释责任。

| 服务 | 业务职责 | 关键约束 |
| --- | --- | --- |
| SolutionManagement | 方案列表、模型目录、创建、保存、准备 | Save 不执行模型；Prepare 原子冻结资产并创建 requested Run，不继承批准 |
| PromptDraftManagement / SemanticPromptDrafts | 草稿修订、校验、冻结与回执 | CAS 修订、来源可追溯；冻结不等于评测、批准或发布 |
| ProfileManagement / SuiteManagement / AssetCatalog | 不可变版本注册、目录与精确资产读取 | 固定身份/摘要；缺失或损坏拒绝，不隐式 latest/文件回退 |
| EvaluationManagement | 评测读取、计划、证据、审核、未知处置、最终评审/复审 | 原 Run/版本及冻结规则；Start/Cancel 执行命令走 MQ |
| PublicationManagement | 发布、停用、回退、历史与原命令回执 | 重建完整质量门槛，精确 selector/预期指针/确认；不调用模型 |
| QuotaManagement | 有效额度、修改/历史/回退、配置状态 | 完整替换与 CAS；部署硬上限、已有预留和 UTC 日界线仍有效 |
| ParticipantManagement | 原生成状态、诊断与恢复回执 | Retry 执行命令走 MQ；当前访问关系和未知风险需重新检查 |
| RuntimeManagement / FlowManagement | 范围内运行诊断与流程投影 | 只读，不续租、不触发评测/生成/发布 |

共享资产目录和发布 selector 保留共享配置语义；机构私有草稿、方案、Run 和原操作者命令回执保持各自隔离。不能因为共享资产可见而读取别人的报告、模型正文或命令回执。

## 命令、回执与结果未知

写操作使用稳定 command_id、明确预期版本或指针、原因及接口要求的确认字段。相同命令同正文返回原结果，同命令不同正文冲突；时间由服务端生成。回执读取核对原机构和原操作者，历史审计读接口不放宽回执归属。

网络超时与畸形成功响应可能发生在事务提交之后。客户端保留原命令，先用对应 GetReceipt/GetFreezeReceipt 等入口读回，不自动新建命令。版本冲突、非法参数、不存在/不属于范围和依赖失败分别按协议错误表达；错误不输出内部异常、资产正文或供应商原文。

发布 Rollback 选择已有明确 publication，并重新核实原冻结证据和门槛；它是配置指针变更，与镜像/数据库回滚不同。已有接单工作继续使用原 publication 与调用回执，新准入使用当前有效配置。停用某场景不授权跨场景 fallback。

## 验收边界

自动化测试可证明 CAS、事务、身份范围、Schema 与恢复契约。管理员保存/刷新、并发编辑、断线原命令恢复、实际审核来源、发布/停用/回退和真实参与者结果需另外取证。保留 AI 代读的真实披露，不把自动评审或委托 AI 阅读记为独立人工审核。
