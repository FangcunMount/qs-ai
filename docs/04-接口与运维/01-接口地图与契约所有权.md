# 接口地图与契约所有权

现行说明；源码基线 `c977cb9`。qs-ai 接收 QS 的可信服务命令，持有 AI 生命周期与治理证据；IAM 与 QS 仍分别持有身份关系、业务权限和标准报告事实。

## 接入地图

| 通道 | 用途 | 权威入口 |
| --- | --- | --- |
| HTTP | `/healthz`、`/readyz`、`/metrics` 运维观测 | [HTTP 路由](../../src/qs_ai/transport/http/)；没有独立用户会话业务路由 |
| MQ | Start、Change、参与者 Retry、评测 Start/Cancel；命令回执、解读/评测事件及最终 ACK | [messaging.proto](../../integrations/workflow/proto/messaging.proto)、[消息装配](../../src/qs_ai/bootstrap/messaging.py) |
| qs-ai 入站 mTLS gRPC | 能力预检、治理读写、运行诊断与按精确引用读取 MQ 正文 | [服务注册](../../src/qs_ai/bootstrap/grpc_server.py)、[workflow.proto](../../integrations/workflow/proto/workflow.proto) |
| QS 出站 mTLS gRPC | 当前资源授权复核、读取 QS 持久 MQ 正文 | [QSAccessSource](../../src/qs_ai/infrastructure/qs_server/access.py)、[PayloadResolver](../../src/qs_ai/infrastructure/workflow_transport/payloads.py) |
| 模型 HTTPS | 经冻结路线选择的供应商请求与原始回执 | [模型路由器](../../src/qs_ai/infrastructure/models/router.py)；不是客户端业务 API |

旧 gRPC 的 `Commands.Start/Change`、`ParticipantManagement.Retry`、`EvaluationManagement.Start/Cancel` 保留协议定义用于明确拒绝，不能作为接单入口。可信 QS 得到 `FAILED_PRECONDITION`；不可信工作负载先得到 `PERMISSION_DENIED`。规则同时位于 [拦截器](../../src/qs_ai/transport/grpc/mq_cutover.py) 与对应服务方法，关闭配置不能恢复旧写路径。

## 契约所有权与变更

| 契约 | 维护者与校验 | 文档职责 |
| --- | --- | --- |
| `workflow.proto`、`messaging.proto` | qs-ai 持有；QS 同步副本；[生成检查](../../scripts/generate_workflow_proto.py)检测漂移 | [QS 接入](02-QS接入与消息契约.md)、[治理语义](03-治理接口与可信委托.md) |
| QS 报告/授权 proto | QS 持有；qs-ai 按 [manifest](../../integrations/qs_server/manifest.json) 固定来源与摘要；[生成检查](../../scripts/generate_qs_proto.py)检测漂移 | [QS 接入材料](../../integrations/qs_server/README.md) |
| 报告快照 | QS 生成事实，AI 校验关联和输入版本 | [快照格式](../../integrations/qs_server/report-snapshot.md) |
| 模型输入/输出、Prompt、评测初始化材料 | Schema/manifest 保留机器版本与来源；运行时使用 MySQL 中的冻结资产 | [规范](../../integrations/qs_server/schemas/README.md)、[Prompt](../../integrations/qs_server/prompts/README.md)、[评测](../../integrations/qs_server/evaluation/README.md) |
| 数据库结构 | [Alembic 迁移账本](../../migrations/versions/) | [部署与回滚](05-部署迁移与兼容回滚.md)；不手写第二份完整 DDL |

协议字段号、枚举含义及可选字段存在性属于兼容契约。新增字段需同步生成代码和消费者，不能把 absent 当作 false 或默认成功。发布生产者前核实消费者能够读该版本；旧冻结请求、资产、调用回执按原版本读取，不因部署转换身份。

## 证据边界

结构校验、跨语言测试、部署探针、模型质量审核、实际参与者结果和端侧展示分别取证。能力预检表示当前配置与输入满足可用条件，服务证书表示工作负载可信；二者都不等于用户授权、容量预留、已接单或业务成功。
