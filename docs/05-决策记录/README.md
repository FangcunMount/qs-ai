## 怎样使用这些记录

理解当前行为，先读表中对应实现设计，再回到决策篇评估代价；提出替代方案时，按该篇的重新决策条件明确需要改变的所有权、事务与恢复规则。现场故障仍从 [排障与受控恢复](../04-接口与运维/06-排障与受控恢复.md) 取证，架构取舍不能代替原业务记录。

后续正式决策应记录问题、约束、候选、选择、代价、实现状态、验证与替代条件，并保留旧结论及其状态。历史过程材料留在归档层；本文索引的现行事实与核对基线由各篇维护。
