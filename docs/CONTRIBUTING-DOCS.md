# qs-ai 文档维护约定

本文适用于根 README、`docs/00` 至 `docs/05`，以及 `configs/`、`integrations/`、`deploy/` 的现行接入说明。读者入口见 [文档地图](README.md)。

## 事实来源

1. 当前运行装配和源码：`src/qs_ai/bootstrap/`、用例、领域与具体持久化实现。
2. 机器契约与配置：proto、JSON Schema、资产 manifest、`configs/`、Alembic、`pyproject.toml` 与锁文件。
3. 与对应分支直接绑定的测试；运行结论还必须有版本、环境和时间窗口。
4. 现行设计正文。
5. 日期证据、规划和归档，分别只证明其声明范围。

不能从文件名、目录或接口声明推断可用性，必须核对入口注册、调用者、实现、错误语义和测试。旧材料可提供术语与设计线索，但进入现行正文前重新核对。没有可证明的历史动机时，写“基于当前约束的设计分析”。

## 目录与单一事实归属

| 目录 | 拥有的问题 |
| --- | --- |
| `00-总览` | 系统边界、术语、两条主链、代码与能力地图 |
| `01-运行时` | 单进程、装配、作用域、后台调度和关闭 |
| `02-业务模块` | 解读、治理、评测、发布的模型与规则 |
| `03-基础设施` | 事务、恢复、消息、模型适配、容量和观测 |
| `04-接口与运维` | 契约接入、配置开发、部署和受控操作 |
| `05-决策记录` | 已采用选择、替代方案、代价和重新决策条件 |
| `evidence` | 带日期、版本、环境的不可外推证据 |
| `_plans` | 未实施方案、演进约束和待绑定的验收缺口 |
| `_archive` | 保留原始过程和历史语境，无当前事实所有权 |

同一规则只在一个主题讲透，其余入口回链。源码目录和文档目录不必一一对应：execution 是应用支持，publication 属于治理能力。领域上下文判断须依据规则和依赖，不依据目录。

## 正文要求

长文先给本文回答和结论，再用图表建立主模型。随后解释问题与约束、概念和责任、不变量、正常链路、事务/并发/失败窗口、采用方案的理由与代价、替代方案、当前限制、源码与测试证据以及验证入口。不机械追求标题数量，但不能只列文件路径、API 或开发批次。

源码和契约使用本仓库相对链接；外部仓库按明确版本或 commit 链接。正式正文禁止依赖个人机器绝对路径。远程链接不由本地校验联网确认；引用方负责核对权限和版本。跨服务表述不能复制 IAM 的身份设计或 QS 的报告事实所有权。

模型、字段、版本名保留真实名称，中文解释业务含义。AI Profile 和 IAM Profile 必须区分。未确认生成输出不得提前称为正式成果；结构合法、语义评测、实际审核与业务验收分别描述。

## 状态与证据

规范化元数据集中在 [document-closure.json](document-closure.json)：

- 文档：`aligned`、`needs_review`、`drifted`、`planned`。
- 实现：`implemented`、`partial`、`planned`、`not_applicable`。
- 验证：源码、仓库测试、CI、部署健康、真实业务、设备/人工验收分别记录。

`aligned + partial` 表示文档准确描述部分实现。源码存在不代表生产已启用。缺少当前环境绑定的运行结论记为 `unknown`。正文写“当前成立”的规则必须有可回查的实现来源。

日期证据记录环境、完整源码/镜像标识、时间、方法、结果与局限，测试数量保留原日期。不能用健康检查、Broker 确认、保存 publication 或机器语义评测替代真实业务和质量认可。

## 归档与迁移

本次历史快照按原字节保存，并由摘要清单验证；不刷新日期、不修改历史结论。归档不参与默认现行结构/链接检查，但仍校验快照字节与迁移映射。现行正文不能借归档证明当前行为；历史导航、来源映射和证据出处可引用归档。

新增过程记录直接放日期证据或规划目录，成熟规则提炼进现行正文。移动前明确继承正文和未完成项去向；不要把尚受支持的旧版本契约当废弃接口。归档不代表清库、业务能力退役或验收关闭。

## 修改与检查

改变装配、接口、状态机、失败语义、配置默认值、数据结构或兼容规则时，同步正文、导航和闭包的 source 摘要。source 摘要发生变化先复核文档，禁止只刷新 hash 来绕过审查。新增现行文档要登记 owner、来源和验证入口。

```sh
uv run python scripts/check_docs.py
uv run pytest -q tests/test_docs.py
uv run python scripts/generate_qs_proto.py --check
uv run python scripts/generate_workflow_proto.py --check
uv run python scripts/generate_messaging_proto.py --check
```

文档门禁检查链接、路径、闭包覆盖、源码摘要、归档保全和少量关键事实；它不理解全部自然语言，也不证明部署、模型效果或业务验收。业务代码未变更时不因文档迁移启动生产、真实模型或破坏性故障实验。
