# 评测与质量审核

准备好的 Run 能否成为发布证据，需要沿候选生成、裁判、门槛和人工审核逐项判断。本组只有一篇现行正文，按下表的问题可以找到相应段落。

| 阅读入口 | 要回答的问题 |
| --- | --- |
| [评测候选、门槛与审核设计](01-评测候选门槛与审核设计.md)：Run 与调用证据 | 35 个候选槽怎样固定？正常生成/裁判次数与最坏预留预算有什么区别？Candidate、Execution 与响应回执怎样关联？ |
| 同篇：G1～G5 与 Finalize | 完成率分母取什么？确定性断言、语义判断、分数与双职责签名怎样共同形成门槛？Preview 通过后为何还需要原 version 的 Finalize？ |
| 同篇：技术恢复、取消与复审 | unknown 可以怎样处置？取消何时仍在排空？语义矛盾复审保留哪些原证据，哪些失败不能被它覆盖？ |
