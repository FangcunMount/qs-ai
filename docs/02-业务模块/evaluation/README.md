# 评测与质量审核

评测验证一组冻结资产在固定案例计划上的执行与内容质量，并建立人工责任。合法 JSON、模型调用成功、确定性断言通过和审核批准是不同事实。

[评测候选、门槛与审核设计](01-评测候选门槛与审核设计.md) 是本组现行正文，覆盖冻结身份、候选与调用回执、状态变化、并发、失败恢复、双角色审核、取消、废弃和有限复审。阈值和预算以 Run 原冻结策略为准。
