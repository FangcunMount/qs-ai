# 发布与生效指针

本组回答“之后的新请求采用哪套配置”。已有 approved Run 时，从发布正文核对证据、selector 和预期指针；正在追查旧请求时，则从它保存的原 Publication 开始。

| 阅读入口 | 要回答的问题 |
| --- | --- |
| [发布证据与生效指针设计](01-发布证据与生效指针设计.md)：记录与 selector | Publication、Pointer、Change 和 Receipt 各保存什么？精确 MBTI 槽与量表选择有什么区别？机构授权为什么仍会改变共享指针？ |
| 同篇：证据复核、锁序与 P1/P2 例子 | approved 之后还要重算哪些证据？Publish、Rollback、Disable 怎样检查 version 和 active ID，并在事务中改变指针？ |
| 同篇：原回执与既有请求 | 返回丢失后怎样读回原命令？暂停或回退为何不改写已经接单请求的配置？ |
