# 业务模块阅读地图

本层解释 qs-ai 的业务对象、规则和状态变化。核对基线：`c977cb9`，2026-10-06；生产配置、当前生效发布及真实业务验收需另行绑定环境与时间核证。

四个目录是文档责任分组，不能据此推导出四个独立 DDD 上下文。解读是服务业务；治理、评测与发布共同管理可执行配置。后台执行、租约和模型回执属于应用与基础设施支持。

| [方案与资产治理](governance/README.md) | 可编辑方案如何原子冻结成可评测的资产集合 | 治理产品与资产维护者 |

QS 负责测评、标准报告事实与资源授权；qs-ai 负责 AI 适用性、输入输出契约、执行与成果。AI Profile 是生成策略及选择器资产，与 IAM 中的 Profile 身份概念不同。身份和权限基础设计在 IAM 维护；本层只记录 qs-ai 消费可信身份和 QS 委托的约束。
