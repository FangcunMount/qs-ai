# 业务模块

要改变一份解读的内容，先找到它采用的报告事实和生成配置；要改变之后所有请求采用的配置，则要沿方案、评测和发布推进。下面四个目录按这些业务问题分工，是文档分组，不代表四个独立服务。

| 入口 | 这里能回答的具体问题 |
| --- | --- |
| [解读与成果](interpretation/README.md) | 报告怎样被接受为冻结输入？执行时怎样复核访问权？原模型响应如何形成 Artifact？量表、MBTI 单篇与三主题各有什么契约？ |
| [方案与资产治理](governance/README.md) | 从模板或保留来源创建方案后，可以修改什么？Save 与 Prepare 怎样处理 revision、资产版本和 requested Run？模板缺失或来源冲突如何拒绝？ |
| [评测与质量审核](evaluation/README.md) | 一个候选与生成/裁判调用怎样关联？固定案例、G1～G5、双职责审核及 Finalize 分别证明什么？取消、unknown 和复审各能改变什么？ |
| [发布与生效指针](publication/README.md) | approved Run 为什么还要重新核证？全局 selector 怎样选择配置？发布、停用和回退如何影响新请求，又如何保留既有请求？ |
