# 解读与成果

解读把 QS 已授权的标准报告事实转换为可追溯的 AI 成果。报告事实、生成推断和通用参考必须保持可区分；保存事实不会保存永久访问权。

1. [解读、冻结输入与成果设计](01-解读冻结输入与成果设计.md)：正常链路、对象、状态、事务和失败边界。
2. [MBTI 报告事实与版本契约](02-MBTI报告事实与版本契约.md)：精确模型、四轴投影、报告单主题与三主题版本矩阵。
3. [MBTI 三主题与参考材料契约](03-MBTI三主题与参考材料契约.md)：主题、依据、选取参考、成果来源和恢复。
4. [报告 AI 能力预检契约](04-报告AI能力预检契约.md)：报告就绪与 AI 可用的区分及原因码。
5. [量表兼容与回执重建](05-量表兼容与回执重建.md)：旧输入、Prompt、Profile 和回执的保护范围。
