# 方案与资产治理

治理把可编辑内容转成固定身份、版本及摘要的可执行资产。注册、冻结、准备、评测、审核和发布是不同完成点，任何一个中间步骤均不直接开放业务。

- [方案资产与原子准备设计](01-方案资产与原子准备设计.md)：Solution、Profile、Prompt、Route、Schema、Suite 及 Prepare 的事务。
- [MBTI 模板与方案来源契约](02-MBTI模板与方案来源契约.md)：两个受控根模板的列举、精确引用、场景继承和错误语义。
- [评测与质量审核](../evaluation/README.md)：准备后的 Run 如何获得发布资格。
- [发布与生命周期](../publication/README.md)：生效指针如何改变新请求的配置。
