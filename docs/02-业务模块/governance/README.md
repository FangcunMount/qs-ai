本组拥有方案来源、编辑和冻结规则；报告事实属于 [解读契约](../interpretation/README.md)，候选质量与审核属于评测，生效范围属于发布。Prepare 已提交时应沿返回的原 Run 继续；它本身没有排队执行或移动发布指针。
